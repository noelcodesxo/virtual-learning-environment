# Design System: Virtual Learning Environment

## Overview

**Creative North Star: "The Focused Learning Instrument"**

The white workspace, light orchid navigation rail, fine lavender rules, and sparse conversation trace create a precise, future-facing tool for independent learning. Each workflow keeps one clear next action.

## Colors

Paper is the dominant workspace surface. Ink carries reading. Lilac marks selection and user-authored states. Plum identifies focus and primary actions.

**The Purple-Has-a-Job Rule.** Purple provides orientation, selection, focus, and primary action. The workspace remains white.

## Typography

DM Sans is used for interface reading and titles. DM Mono is reserved for compact technical metadata.

## Layout

Desktop uses a 254px navigation rail and flexible white work surface. Headers end with a 1px lavender separator. Chat content uses an 860px reading column; form and library workflows use 920px.

## Elevation & Depth

Use borders and tonal differences instead of shadows.

## Shapes

Controls use 6px corners and contained surfaces use 8px corners.

## Components

The wordmark is text only. Chat uses pale lilac user messages, white assistant messages, an editable title, and a composer with a single Plum send control. Exam and library workflows use spacious white planes and one direct primary action.

## Do's and Don'ts

### Do:

- **Do** retain the white workspace as the dominant surface.
- **Do** use light purple for the rail and pale lilac for selected or user-authored states.
- **Do** use a clear 1px header separator.

### Don't:

- **Don't** add a permanent study-plan panel or attachment controls to chat.
- **Don't** use blue, cyan, neon, gradients, glass effects, or dashboard widgets.
- **Don't** add an icon beside the product name.
